### Task 4: Check Data Types

Verify whether the following columns have the correct data types.

| Column       | Expected Data Type                    |
| ------------ | ------------------------------------- |
| Ship Mode    | Text                                  |
| Segment      | Text                                  |
| Country      | Text                                  |
| City         | Text                                  |
| State        | Text                                  |
| Postal Code  | Text or an appropriate numeric format |
| Region       | Text                                  |
| Category     | Text                                  |
| Sub-Category | Text                                  |
| Sales        | Number                                |
| Quantity     | Whole Number                          |
| Discount     | Number                                |
| Profit       | Number                                |

For each column, check its actual data type and compare it with the expected data type.

Record any data type issues you find.

### Task 5: Create a Data Quality Report

Create a new worksheet in Excel.

**Worksheet Name:** `Data_Quality_Report`

Include the following information in the report:

1. Total Rows
2. Total Columns
3. Missing Values
4. Duplicate Rows
5. Data Type Issues
6. Problems Found
7. Recommended Actions

If you do not find any data quality issues, explicitly mention that in your report.

**Important:** Do not modify or delete any data without verifying the issues first.



## Project Objective

The objective of this project is to develop practical data analysis skills by performing initial data quality checks on a Superstore dataset using Microsoft Excel.

By completing this project, you will learn how to inspect a dataset, identify missing values, detect duplicate records, validate data types, and prepare a professional data quality report.
